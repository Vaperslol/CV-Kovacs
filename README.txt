# Kovács Péter – CV weboldal

## Fájlok
- `index.html` – a teljes CV/portfólió tartalma
- `style.css` – reszponzív megjelenés
- `script.js` – mobilmenü, placeholder linkek és évszám

## Amit még ki kell tölteni
1. Az `index.html`-ben a `HELY A FOTÓNAK` részt cseréld le a saját CV-fotódra. KÉSZ
2. A GitHub linkeket cseréld le a saját profilod URL-jére. KÉSZ
3. A LinkedIn linket cseréld le a saját profilod URL-jére. NEM FOGOM, MERT NINCS :(
4. A két projekt linkjét cseréld le az elkészült weboldalak URL-jére. KÉSZ

A weboldal mobilra is optimalizált, és a menüpontok belső horgonylinkekkel navigálnak az egyes CV-szekciókhoz. HURRÁ
